STUZEN TECHNOLOGIES - offline edition
=====================================

Open index.html in a web browser (double-click it).

Files:
  index.html  Page structure
  styles.css  All styles and embedded webfonts
  app.js      Application code (classic script, no build step needed)
  assets/     Images used by the pages

Pages use hash URLs, for example:
  index.html#/about
  index.html#/services/secure-website-building

No server or internet connection is required. External links
(email, phone, WhatsApp, Instagram, Google Maps) open normally.
